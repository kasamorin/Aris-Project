# UI 设计任务单（v1.0）

> 你来画图，我只描述「要设计哪些页面、每个页面有什么元素」。所有页面共用同一套外壳（§4.1）。
> 图只定整体骨架与分区，图里没画到的细节问开发者，不自行延伸。

## 全局外壳（所有页面共用）

- 三段式响应式：桌面/平板展开（左侧竖向导航 + 中部图标+文字导航项，分组折叠 chevron）、桌面折叠（图标轨 ~56 px，hover 展开）、手机（左上汉堡 → 覆盖抽屉）。
- 顶部：品牌名「Aris Project」+ `Dashboard | Chat` 分段切换（同一外壳里切，WebChat 不是独立门户）。
- 切到 Chat 时：导航项换成**角色列表**（一行一个角色，头像位预留 v1.x）。
- 底部固定区：外链（GitHub 等）。
- 右下角折叠按钮 `«`。
- 深浅色跟随系统（`prefers-color-scheme`），主题色预设 6 色（蓝/青/绿/紫/橙/粉）+ 自定义取色器；默认蓝（浅 `#2563eb` / 深 `#3b82f6`）。
- 侧栏品牌区一行 `vX.Y.Z`（折叠成图标轨时隐藏）；有新版本时变成「新版本 vY.Y.Y ↗」。
- 三项调试开关（思考链 / 工具调用 / 记忆命中）：默认全关，用户可开，状态存 `<data>/state/`。

## 页面清单

### P1 Dashboard（运维首页）

- 服务状态、模块开关概览、最近审计摘要、快捷入口（设置 / 工具 / 日志 / 知识库）。
- 三态：加载 / 空 / 错。

### P2 设置页

- 配置档切换 / 新建档；分类筛选；搜索；单套完整列表（组内分 section、条件显隐）。
- 条目卡片 = 名称 + 一句简述 + 右侧控件（开关 / 文本 / 数字 / 下拉 / 取色）。
- 左下角：存在未保存改动时出现「保存」按钮（写 TOML + 重载）。
- 原始键名 + 所在 toml 文件：由前端状态 `show_raw_keys` 控制（默认关）。
- **实验室 tab**：合成 tab，所有标 `experimental=True` 的配置项自动归入，原所属 tab 也保留。
- 字段元数据由代码生成，前端只消费。

### P3 工具页

- 工具列表：名称 / 状态（启用/关闭）/ 来源（builtin / knowledge / mcp / 插件）。
- 开关；来源只读展示。

### P4 统一连接页（提供商 / 模型）

- 提供商列表（按 API 格式适配）；模型列表（允许列表 vs 联网获取）；能力标记（思考/工具/视觉/语音）；
  手动增删模型；模型元信息（上下文长度）。

### P5 搜索顺序页

- 顶部输入框写顺序（`bing,tavily,exa,…`）；下方列表可拖动；双向实时同步。
- 引擎启停 / 新建（Tavily 兼容协议端点 + MCP 来源）；Exa 不可用时显示原因。

### P6 知识库页

- 摄入 / 列表 / 删除 / 搜索 / 重索引；任务进度（复用 `webui/tasks` 轮询）。

### P7 记忆 / 角色页

- 角色列表与当前会话；人物卡 / 重要事件（只读展示为主）；记忆检索调试。

### P8 WebChat（对话界面）

- 消息流（文本 + 图片）；输入区（文本 + 图片上传）；流式输出带「停止」按钮；语音切换（实验性警告）。
- 调试信息可选显示（思考链 / 工具调用 / 记忆命中）。
- 消息气泡要显示图片/语音/记忆相关 UI。

### P9 关于页

- 中间项目图标；下方一排联系方式（B 站、X、GitHub 等）；图标下方版本信息（当前版本 + 检查状态，点一下手动检查）；
  「不再提示此版本」+ 发布页外链；白色图标（固定白 + 深色描边）触发彩蛋（外链）。

### P10 日志 / 审计页

- 日志查看（按频道 `[boot]/[chat]/[tool]/[llm]/[worker]/[duplex]`）；审计内存环形缓冲（`webui.show_audit` 控制入口）。

### P11 组件页

- `aris components list` 对应的 WebUI 视图：PG / embedding 版本与校验。

### P12 MCP 页

- 服务器列表、连接状态、超时/退避配置（复用元数据，hidden 字段）。

### P13 模型管理（本地推理）

- 主页面卡片列表 + 管理弹窗（不用右侧抽屉）；状态：未下载/已下载/启动中/运行中/停止中/出错。
- 来源三分：推荐模型 / 网络下载 / 本地导入（风险声明 + 复制到 `data/models/`）。
- 模型类型：普通 / 双工 / embedding。

### P14 GUI 壳（MyGO webview）

- 复用同一套前端产物；只做壳（标题栏、拖拽区、无地址栏假设）。

## 通用元素

- 三态组件 include：`_state_loading.html` / `_state_empty.html` / `_state_error.html`。
- 表单字段级错误 inline；保存成功顶部 toast（3 s 自动消失）。
- SSE 断线：浏览器自带重连 + onopen 恢复文案 + 断线分隔线。
- 错误文案服务端集中映射，前端只显示；禁止 `alert()`。
