# 历史版本变更记录（changelogs/）

`CHANGELOG.md` 只保留 `[Unreleased]` 与**当前最新版本**；更早的版本整段移到本目录，
一个版本一个文件：`changelogs/<版本>.md`（与 tag 的数字一致，如 `v0.4.4` → `0.4.4.md`）。

## 索引

- [`0.4.4`](./0.4.4.md) - 2026-10-30（地基版：数据目录、配置收口、CLI 事实入口）

当前最新版本见根 [`CHANGELOG.md`](../CHANGELOG.md)。

## 格式

```markdown
## [<版本>] - YYYY-MM-DD

### 亮点        （可选，人话写 2~3 条）
### 新增
### 改进
### 修复
### 升级注意    （不兼容项写清迁移方式）
```

- 面向**使用者**：写可见变化与操作影响，不写内部重构细节。
- 没有内容的分类直接省略，不写「无」。
- 与 tag 渠道无关（beta / 正式 / alpha 共用同一条数字线，只用数字命名文件）。
- `CHANGELOG.md` 超过约 2000 行或满一年时，把最旧的版本移到本目录（自动化留到 v1）。
